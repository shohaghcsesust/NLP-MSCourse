This folder contains the exact input sentences used for the Text-to-Speech (TTS)
practical experiment: 5 sentences per language (English, Bangla, Hindi) = 15 total,
all deliberately chosen for complex/difficult pronunciation (tongue-twisters and
phonetically dense constructed sentences with repeated or confusable consonant
clusters), rather than simple everyday sentences, to meaningfully stress-test both
the TTS tools and the round-trip recognizer used to verify them.

E1-E5 = English, B1-B5 = Bangla, H1-H5 = Hindi.
See Report/master_results.json / the report's "why hard" column for the specific
phonetic reasoning behind each sentence.
